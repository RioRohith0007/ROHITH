# Rohith R — AI/ML Engineer Portfolio

Dark-navy, electric-blue portfolio with an interactive spider-web background and four project case studies.

## Run in VS Code

1. Install Node.js (version 18 or newer) from nodejs.org.
2. Unzip the project and open the `rohith` folder in VS Code (File > Open Folder).
3. Open the terminal (Ctrl + `) and run:

```bash
npm install
npm run dev
```

4. Open http://localhost:5173 in your browser. Refresh the page to replay the knife intro.

The opening animation is in `src/components/Intro.tsx`. The contact form is `src/components/ContactForm.tsx` (the first message you send needs a one-time FormSubmit activation from your email).

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build
npm run preview    # serve the production build
```

## Deploy for free with GitHub Pages

1. Upload this project to the **public** `RioRohith0007/ROHITH.github.io` repository on its `main` branch.
2. In the repository, open **Settings > Pages** and set the build and deployment source to **GitHub Actions**.
3. The included workflow builds and deploys the site on every push to `main`. Once it completes, GitHub shows the public URL under **Settings > Pages** (normally `https://RioRohith0007.github.io/ROHITH.github.io/`).

The Vite build automatically uses the repository subpath on GitHub Pages; local development continues to use the root path.

## What is where

| Path | Purpose |
| --- | --- |
| `src/web/engine.ts` | Spider-web simulation (pure TypeScript, no DOM): nodes, edges, pointer forces, click waves |
| `src/web/renderer.ts` | Canvas drawing for the web |
| `src/components/SpiderWeb.tsx` | Canvas component and mouse / click / touch handling |
| `src/components/Projects.tsx` | The four project cards |
| `src/components/ProjectModal.tsx` | Full-screen case study |
| `src/components/ArchitectureFlow.tsx`, `Workflow.tsx` | Interactive architecture diagram and animated workflow |
| `src/components/ProjectImage.tsx` | Image with reserved aspect ratio, loading and error states |
| `src/data/portfolio.ts` | Resume content |
| `src/data/projectDetails.ts` | Case-study content, architecture graphs, workflow steps |
| `src/design/tokens.ts`, `src/index.css` | Colours and the z-index system |
| `public/assets/projects/*.svg` | Project previews (generated by `npm run previews`) |

## Project previews

The four preview images are original illustrative mockups, not screenshots of deployed apps, and are labelled as such in the UI.
To use a real screenshot, put it in `public/assets/projects/` and change `preview.src` in `src/data/projectDetails.ts`.
`npm run previews` regenerates the mockups from `scripts/build-previews.mjs`.

## Links

A project's GitHub or live-demo button only appears when `github` or `live` is set on that project in `src/data/portfolio.ts`. None are set, so no placeholder links are shown.

## Z-index layers

0 background, 1 spider-web, 2 ambient, 5 content, 10 cards, 20 navigation, 30 overlays, 40 modals, 50 loader (`--z-*` variables in `src/index.css`).
